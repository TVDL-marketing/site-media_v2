# TVDL Media Center v2 — Accès rapide (débutant)

Si vous voyez “il n’y a rien” sur GitHub, c’est normal : un prototype web statique **ne s’exécute pas directement** dans la vue liste des fichiers.

## Ouvrir la maquette en 2 minutes

1. Cliquez sur le bouton vert **Code** dans GitHub.
2. Cliquez sur **Download ZIP**.
3. Décompressez le ZIP sur votre ordinateur.
4. Ouvrez le dossier extrait.
5. Double-cliquez sur **`index.html`**.

Le prototype démarre localement, sans installation, sans backend.

## Si le navigateur bloque certaines données
Le prototype inclut un fallback automatique des données pour fonctionner même en local.

## Fichiers clés
- `index.html` : point d’entrée.
- `assets/` : styles, scripts, images.
- `data/` : données simulées.
- `README.txt` : documentation fonctionnelle détaillée (rôles, limites, etc.).
- Pas de fichiers binaires dans le dépôt (placeholders uniquement).
